写作提示

Markdown 驱动

在 _posts 文件夹中添加新的 Markdown 文件即可发布文章，使用标准 Markdown 语法进行排版。

图片与图库

将图片放在 assets/images 下，通过 ![]() 语法插入，系统会自动应用苹果风格的圆角阴影。

附件下载

在文章 Front Matter 中使用 attachments 列表，即可展示下载按钮，适用于 PDF、压缩包或 Keynote 文件。
