<section class="section container about">
  <h1>关于本站</h1>
  <p>Apple Inspired Journal 是一款追求极简与优雅的静态博客主题，借鉴了苹果官网的视觉语言。其核心特性如下：</p>
  <ul>
    <li>使用 Markdown 创作内容，并自动适配现代化排版。</li>
    <li>支持插入高清图片，图片会自动应用柔和阴影与圆角。</li>
    <li>通过 front matter 配置附件列表，适合分享 Keynote、PDF 或压缩包。</li>
    <li>响应式设计，桌面与移动端均有一致体验。</li>
  </ul>
  <p>要发布新文章，只需在 <code>_posts</code> 目录中添加一个符合 Jekyll 命名规范的 Markdown 文件，例如 <code>2024-05-01-new-feature.md</code>。</p>
</section>
